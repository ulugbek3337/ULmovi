# Xavfsizlik siyosati

ULmovi xavfsizligini jiddiy qabul qilamiz. Zaiflik aniqlasangiz, uni mas’uliyat bilan xabar qiling.

## Zaiflik haqida xabar berish

Iltimos, zaiflik tafsilotlarini ommaviy GitHub issue, pull request yoki muhokamada e’lon qilmang.

Repository’da GitHub Private vulnerability reporting yoqilgan bo‘lsa, **Security → Advisories → Report a vulnerability** orqali xabar yuboring. Agar bu imkoniyat ko‘rinmasa, repository egasi bilan GitHub orqali shaxsiy aloqa kanalini so‘rang.

## Xabarda nimalar bo‘lishi kerak?

- Zaiflik turi va ta’sirlangan komponent/fayl.
- Takrorlash uchun aniq qadamlar.
- Ta’sir doirasi va ehtimoliy xavf.
- Zarur bo‘lsa, maxfiy ma’lumotlarni yashirgan log yoki screenshot.
- Muammoni xavfsiz qayta tekshirish uchun tavsiya.

## Mas’uliyatli tekshiruv

- Faqat o‘zingizga tegishli yoki sinashga aniq ruxsatingiz bo‘lgan muhitda tekshiring.
- Haqiqiy foydalanuvchi ma’lumotlarini ko‘chirmang, o‘zgartirmang yoki oshkor qilmang.
- Xizmatni izdan chiqaruvchi yuklama, DoS yoki ma’lumotlarni o‘chiruvchi testlarni bajarmang.
- Zaiflikni ommaga e’lon qilishdan oldin tuzatish uchun oqilona muddat bering.

## Qo‘llab-quvvatlash doirasi

Ushbu siyosat ULmovi repository’sidagi amaldagi kodga tegishli. Uchinchi tomon hosting, brauzer, kutubxona yoki tashqi xizmatlardagi zaifliklar tegishli provayderga ham xabar qilinishi kerak.
